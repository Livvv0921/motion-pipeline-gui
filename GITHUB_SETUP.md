# GitHub publishing plan

## Recommended repository

**Name:** `motion-pipeline-gui`

**Description:**
Desktop PySide6 GUI for a DeepLabCut + Aniposelib multi-camera motion-analysis workflow with 3D triangulation, Peak Lab, Movement Lab, Compare Lab, visualization, and concurrent backend jobs.

**Recommended visibility:** Private initially, until the lab/PI chooses a license and confirms what can be shared publicly.

**Suggested topics:**

`deeplabcut` `aniposelib` `motion-capture` `pose-estimation` `3d-tracking` `behavior-analysis` `neuroscience` `pyside6` `kinematics` `python`

## First release

- Tag: `v0.5.7`
- Title: `Motion Pipeline GUI v0.5.7`
- Release notes: `docs/RELEASE_NOTES_v0.5.7.md`
- Binary/source bundle to attach: `motion_pipeline_gui_v0.5.7.zip`

## Before making the repository public

1. Choose an explicit software license with the lab/PI.
2. Confirm author/contributor and institutional attribution.
3. Confirm no private paths, animal/subject identifiers, unpublished data, credentials, or lab-only infrastructure are present.
4. Add real GUI screenshots with sensitive details removed.
5. Decide whether GitHub Pages should be enabled from `/docs`.
