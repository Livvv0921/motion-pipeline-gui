# Screenshot checklist

The README should use real v0.5.7 workstation captures rather than mockups.

Recommended files:

1. `docs/images/overview-dark.png`
   - full application
   - dark theme
   - sidebar + docked console visible
   - ideally one backend task running so progress UI is visible

2. `docs/images/peak-lab.png`
   - Peak Lab with a 3D trace loaded
   - selected/enlarged peak visible
   - Manual Review controls visible

3. `docs/images/movement-lab.png`
   - Movement Lab with synchronized video inspector and trace cursor

4. `docs/images/compare-lab.png`
   - Compare Lab with multiple traces in stacked or overlay mode
   - control panel visible or intentionally hidden to show resizing

Capture at normal Windows display scaling if possible. Avoid including private network paths, animal/subject identifiers, unpublished data labels, or other sensitive lab information.

After the screenshots are added, the main README can display an overview image near the top and a 3-image feature gallery below the workflow section.
